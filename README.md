## Shannon

[![GitHub stars](https://img.shields.io/github/stars/KeygraphHQ/shannon?style=flat&logo=github&label=stars&labelColor=191E1D&color=D05121)](https://github.com/KeygraphHQ/shannon)
[![Latest release](https://img.shields.io/github/v/release/KeygraphHQ/shannon?style=flat&label=release&labelColor=191E1D&color=D05121)](https://github.com/KeygraphHQ/shannon/releases)

Shannon is an autonomous AI pentester for web applications and APIs. It reads your source code, maps the attack paths, and runs real exploits against your running app. Only vulnerabilities with a working proof of concept make the report. **No exploit, no report.**

```bash
npx @keygraph/shannon@latest
```

**Your model, your key.** Anthropic, OpenAI, xAI, AWS Bedrock, LLM gateways, or a local model through Ollama, vLLM or LM Studio. Keygraph never proxies your model traffic.

**Local or in CI.** Run it from your terminal, or on pull requests, releases and schedules with the [GitHub Action](https://github.com/KeygraphHQ/shannon-action) and the [GitLab CI/CD component](https://gitlab.com/KeygraphHQ/shannon-ci). The build fails only on proven exploits.

**Reports for people and for tools.** PDF and Markdown for your team, JSON and SARIF 2.1.0 for code scanning and security dashboards.

**Open source** under AGPL-3.0, with commercial licensing available through [shannon@keygraph.io](mailto:shannon@keygraph.io).

[Read the docs](https://keygraph.io/docs/) · [Quick start](https://keygraph.io/docs/tutorials/quick-start/) · [Shannon 3.0 benchmark](https://keygraph.io/shannon-benchmark)

## The Keygraph platform

AppSec and pentesting, on one platform. The Keygraph platform runs an enterprise-hardened build of Shannon continuously across your repositories, with the full AppSec suite around it.

**Pentesting.** Whitebox and blackbox pentesting plus business logic testing, with a working exploit behind every pentest finding.

**Code security.** Agentic SAST, SCA with reachability, and secrets scanning across repository history.

**Findings to fixes.** One record per vulnerability across every scan and scanner, fix pull requests, and fix verification by re-analysis and exploit replay.

**Deployment.** Cloud-hosted, self-hosted, or fully air-gapped. You choose the models, always with your own key.

**Governance.** SSO, SCIM, RBAC, audit logs, Jira sync, and SOC 2 Type II.
